# Domain Ontology Builder

Build a governed domain ontology ensuring every team gets the same answer.

## Pattern
Raw Data -> Entity Ontology -> Semantic View -> Cortex Agent -> Conversational UI

## Steps
1. Define domain entities and relationships
2. Create tables and load data
3. Build semantic view YAML
4. Create Cortex Agent with guardrails
5. Build multi-persona Streamlit app
6. Validate cross-persona consistency
7. Add data quality automation
